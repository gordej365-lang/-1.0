ЭЛЕКТРИЧЕК — обновлённый мобильный интерфейс
=============================================
Содержимое:
- index.html — адаптивный интерфейс, поиск по локальному каталогу станций и фильтры по направлениям.
- data/stations.json — стартовый каталог станций (не полный официальный реестр).

Публикация на GitHub Pages:
1. Загрузите index.html в корень репозитория, заменив прежний index.html.
2. Создайте папку data и загрузите туда stations.json (каталог JSON сейчас подготовлен для дальнейшего расширения; текущий интерфейс использует встроенный список).
3. Подождите завершения GitHub Pages deployment и обновите сайт.

Важно:
- В проекте НЕТ настоящих времён отправления и не выдумываются расписания.
- Каталог станций — демонстрационная стартовая выборка из 40 станций/пунктов, не полный официальный список; названия/направления следует сверить перед публичным использованием.
- Для актуального расписания нужен API/набор данных с разрешённым использованием и серверная интеграция.
- Существующий логотип не был доступен в переданных файлах, поэтому использован временный текстовый знак «Э». Если пришлёте архив исходного сайта, заменим знак на ваш оригинальный логотип.
