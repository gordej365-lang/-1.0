ЭЛЕКТРИЧЕК — Москва и МЦД, версия 4 с серверным подключением API

Запуск:
1. Установи Node.js 20 или новее.
2. Распакуй ZIP и открой терминал в папке проекта.
3. Выполни: npm install
4. Скопируй .env.example в файл .env.
5. В .env укажи действующий ключ: YANDEX_RASP_API_KEY=...
6. Выполни: npm start
7. Открой http://localhost:3000

Для поиска реальных рейсов:
- введи коды станций отправления и назначения и выбери дату;
- сервер отправит запрос к API Яндекс Расписаний;
- секретный ключ хранится на сервере и не передаётся браузеру.

Состав:
- index.html — сайт с вашим логотипом, карточками МЦД и ссылками на официальные источники;
- server.js — защищённый серверный прокси;
- .env.example — шаблон переменных окружения;
- package.json — зависимости;
- .gitignore — исключает .env и node_modules из git.

Важно:
- без действующего API-ключа и кодов станций реальные данные не загрузятся;
- список демонстрационных рейсов не является актуальным расписанием;
- для публичного запуска настрой HTTPS, ограничения частоты запросов и серверные логи без секретов;
- соблюдай условия провайдера и показывай Яндекс Расписания как источник данных.
