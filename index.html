РЕАЛЬНОЕ РАСПИСАНИЕ

Подключить источник данных

Реальные рейсы загружаются через сервер сайта. Секретный API-ключ хранится на сервере и не показывается посетителям.

Опционально

Настрой сервер по инструкции в README и добавь API-ключ в .env. Не вставляй секретный ключ в HTML и не публикуй его в репозитории.
